# Установка

## Что нужно

- SillyTavern
- [SillyTavern-JS-support](https://github.com/MiNtorikaSoul/SillyTavern-JS-support) —
  разрешает выполнять JavaScript внутри сообщений.

Без расширения виджеты всё равно отрисуются: разметка, стили и анимации
работают сами по себе. Не будет только того, что без скриптов не сделать.

## Один раз: служебные скрипты

`dist/service/` — пять регексов, общие для всего пака. Импортируются в
**Extensions → Regex → Import** по одному, в порядке имён файлов.

| Файл | Что делает |
|---|---|
| `00-perf` | глушит анимации виджетов за пределами экрана |
| `01-clean-comments` | вырезает `<!-- -->` из запроса к модели |
| `02-clean-style` | вырезает `<style>` |
| `03-clean-script` | вырезает `<script>` |
| `99-fallback` | прячет сломанные маркеры, чтобы читатель не увидел сырой текст |

Чистильщики `01–03` защищают от HTML, который модель написала сама: сами
виджеты в запрос не попадают, потому что рендер работает только на отображение.

Порядок важен. `99-fallback` обязан идти последним, иначе он съест маркеры
раньше, чем их успеют отрисовать виджеты.

## На каждый трекер: три файла

Папка трекера → язык → внешний вид, и в ней ровно три файла:

```
dist/hud/ru/parchment/
  1-prompt.txt     ← в пресет
  2-regex.json     ← в Regex
  3-cleaner.json   ← в Regex
```

| Скин | Как выглядит |
|---|---|
| `parchment` | лист описи: пергамент, чернила, буквица киноварью, сургучная печать |
| `steel` | приборная панель: тёмный анодированный металл, срезанный угол, светящиеся деления |

Скин ставится **один**. Оба сразу конфликтуют — селекторы у них общие, и
победит тот, что импортирован позже.

**1. Промпт.** Открыть файл, скопировать целиком. В SillyTavern:
**AI Response Configuration → Prompts → новый промпт**, роль **System**,
вставить текст. Поставить его после основных инструкций и включить.

**2. Регекс.** **Extensions → Regex → Import**, выбрать `2-regex.json`.
Он превращает маркер в виджет и работает только на отображение — в запрос к
модели уходит по-прежнему короткая строка.

**3. Чистилка.** Туда же, `3-cleaner.json`. Убирает маркер из запроса, когда
сообщение уходит глубже трёх. Без неё маркеры копятся в контексте навсегда.

Регекс должен стоять в списке **выше** `99-fallback`.

## Язык

Папка `en/` и папка `ru/` — это один и тот же трекер с промптом и подписями
на разных языках. Ставится одна из них, не обе.

Значения внутри виджета модель пишет на языке ролевой, независимо от выбранной
папки: об этом сказано в самом промпте.

Промпт в `parchment/` и в `steel/` одинаковый — скин на него не влияет. Файлы
продублированы, чтобы папку можно было брать целиком, не собирая из двух мест.

## Проверить, что работает

Написать боту что угодно и посмотреть, появилась ли панель. Если вместо
виджета видно `[[VLD_HUD|N=...]]` — не импортирован `2-regex.json` или он стоит
ниже `99-fallback`.

Если не видно вообще ничего, а маркер в ответе был — `99-fallback` съел его
раньше виджета. Переставить порядок.
